    怎么接大模型（一条命令都不用改）

    当前用的是本地规则引擎，好处是断网可用、判定可解释、零成本。要接大模型时，只需替换 classify()，特征抽取与分级逻辑不动——这就是“规则 + 模型”双路融合里的模型路。

    // 伪代码：把本地引擎换成大模型，其余代码不变
async function classify(text){
  const r = await fetch('/api/judge', {
    method:'POST',
    body: JSON.stringify({
      prompt: `你是反诈研判助手。依据给定的 13 类特征分层判断，
               输出 JSON：{score, type, evidence:[{layer, cat, sentence}]}`,
      text
    })
  }).then(r => r.json());
  return normalize(r);   // 归一化后交给同一套分级与解释逻辑
}
    接模型后建议保留规则路兜底：模型输出异常或超时时，自动回落到本地规则，保证老人端永远不会“转圈等不到答案”。
